Practical 7:Performing Databases backups

a)RMAN full databse backup

Open CMD AS Run as Administrator -> mkdir C:\app\oracle\backup -> rman target / -> BACKUP DATABASE FORMAT 'C:\app\oracle\backup\full_backup_%U';

(if Error)
Open CMD AS Run as Administrator -> sqlplus / as sysdba; -> select log_mode from v$database; -> SHUTDOWN MOUNT -> SHUTDOWN IMMEDIATE; -> STARTUP MOUNT; -> ALTER DATABASE ARCHIVELOG; -> select log_mode from v$database; -> alter database open;
then again open CMD AS Run as Administrator ->
mkdir C:\app\oracle\backup -> rman target / -> BACKUP DATABASE FORMAT 'C:\app\oracle\backup\full_backup_%U'; -> 

b)incremental backup
BACKUP INCREMENTAL LEVEL 1 DATABASE FORMAT'C:\app\oracle\backup\incremental_backup_%U';

c)archivelog backup
BACKUP ARCHIVELOG ALL FORMAT 'C:\app\oracle\backup\arch_backup_%U';

d)RMAN backup of control file and SPFILE
BACKUP CURRENT CONTROLFILE FORMAT 'C:\app\oracle\backup\controlfile_backup_%U';

BACKUP SPFILE FORMAT 'C:\app\oracle\backup\spfile_%U.bkp';

e)RMAN backup with compression
BACKUP AS COMPRESSED BACKUPSET DATABASE FORMAT 'C:\app\oracle\backup\compressed_full_backup_%U';

f)Validating backup
RESTORE DATABASE VALIDATE;
RESTORE ARCHIVELOG ALL VALIDATE;

g)Scheduling backup using RMAN
BACKUP DATABASE PLUS ARCHIVELOG;
